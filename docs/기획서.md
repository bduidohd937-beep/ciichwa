# 「나는 어떤 치이카와?」 성격 테스트 — 기획서 v1.0

## 1. 컨셉

- **한 줄**: MBTI 4축(외향/내향·감각/직관/이성/감정/판단/인식)을 질문으로 측정해서, 사용자가 **치이카와 세계관의 어떤 캐릭터와 닮았는지** 알려주는 웹 테스트.
- **톤**: 치이카와 특유의 "귀여운데 살짝 서글픈" 무드. 부드러운 파스텔 + 크림색 배경, 둥근 모서리, 손그림 느낌 타이포.
- **타깃**: SNS(인스타/틱톡/트위터)에서 밈처럼 공유되는 성격 테스트를 즐기는 10~30대.
- **핵심 훅**: 결과 = "당신은 **우사기형**이에요" + 4축 점수 시각화 + 한 줄 밈 캡션 + 원클릭 공유.

> ⚠️ **저작권 고지**: 치이카와(ちいかわ)는 나가노 작가의 캐릭터입니다. 본 프로젝트는 **팬메이드 성격 테스트**이며, 공식 일러스트를 무단 사용하지 않습니다. 캐릭터 표현은 직접 만든 단순 SVG/이모지 스타일로 대체하고, 결과 텍스트는 팬 창작 해석으로 작성합니다. 상업적 배포 시 라이선스 확인 필요.

## 2. 테스트 구조

### 2.1 측정 축 (MBTI 4축)

| 축 | 질문 방향 | 치이카와 세계관 해석 |
|---|---|---|
| **E / I** (에너지) | 사람 많은 곳 vs 혼자 있기 | 우사기·하치와레(E) ↔ 치이카와·네즈미(I) |
| **S / N** (인식) | 현실·실속 vs 상상·직관 | 하치와레(S) ↔ 우사기(N, 즉흥 상상) |
| **T / F** (판단) | 이성·논리 vs 감정·배려 | 네즈미(T) ↔ 치이카와(F) |
| **J / P** (생활) | 계획·정리 vs 즉흥·자유 | 하치와레(J) ↔ 우사기(P) |

### 2.2 문항

- **총 16문항** (4축 × 4문항) — 표준 MBTI 문항 수, 신뢰도 확보.
- 각 문항 **5점 척도** (매우 아니다 ~ 매우 그렇다)가 아니라 **선택지 2개(A/B)** 방식 → SNS 테스트 답게 가볍고 빠름.
- 문항 예시:
  - "주말에 친구가 갑자기 만나자고 하면?" → A: "바로 나가!" / B: "집이 좋은데…"
  - "새로 생긴 간식 가게 앞에서?" → A: "줄 서서라도 시험" / B: "메뉴부터 검색"
  - "사람이 많은 파티에서 나는?" → A: "먼저 말 걸기" / B: "구석에서 관찰"
- 문항 데이터는 별도 JSON/TS 모듈로 관리 → 문구 수정·추가 용이.

### 2.4 결과 화면 구성

1. 캐릭터 카드 (이름 + 한 줄 타이틀 + SVG 초상)
2. **4축 점수 막대그래프** (E↔I, S↔N, T↔F, J↔P 퍼센테이지)
3. 캐릭터 상세 해석 (3~4문장)
4. 케미 추천 ("이 캐릭터와 가장 잘 맞는 친구: ○○")
5. 공유 버튼: 결과 문구 복사 / Web Share API / 결과 이미지 저장(SVG→PNG 캔버스)
6. "다시 테스트" · "친구에게 보내기" 버튼

## 3. 사용자 플로우

```
랜딩 (타이틀 + "테스트 시작" + 소요 시간 1분 안내)
   → 질문 1~16 (진행바, 이전/다음, 선택 시 자동 다음)
   → 결과 계산 (클라이언트 로컬, 서버 불필요)
   → 결과 화면 (캐릭터 + 4축 차트 + 공유)
```

- 뒤로 가기/새로고침 대응: 진행 상태는 `sessionStorage`에 저장.
- 접근성: 키보드 조작(A/B 키, 화살표), 높은 대비, 모바일 1기둥 레이아웃.

## 4. 기술 스택 (안)

| 항목 | 선택 | 사유 |
|---|---|---|
| 프레임워크 | **Vite + React + TypeScript** | 빠른 빌드, 타입 안정성, 배포 단순 |
| 스타일링 | **Tailwind CSS** | 파스텔 테마 빠른 적용, 반응형 |
| 상태 | React state + sessionStorage | 서버 불필요한 완전 정적 SPA |
| 차트 | 직접 만든 CSS 막대 (라이브러리 없음) | 가볍고 스타일 자유 |
| 테스트 | Vitest (결과 매핑 함수 단위 테스트) | 16유형 매핑 정확성 검증 |
| 배포 | **GitHub Pages** (Vite base `./` 상대경로) | 저장소 내 워크플로로 푸시마다 자동 배포, 계정 추가 등록 불필요 |
| 저장소 | **GitHub** (public) | 커밋 → push → Pages 자동 배포 |

## 6. 필요한 에셋 / 자료 (사용자 확인 사항)

1. **캐릭터 이미지**: 공식 이미지 저작권 이슈 → ✅ 직접 단순 SVG 제작(권장) / ❓ 사용자 제공 이미지
2. **폰트**: 무료 한글 폰트 (Pretendard / Gmarket Sans / 나눔손글씨) 중 선택
3. **결과 공유 이미지**: 캡처 라이브러리(html-to-image) 사용 여부
4. **도메인/계정**: GitHub 계정, Vercel 계정 필요 (배포 시)
5. **문구 검수**: 캐릭터별 해석 문구는 팬메이드 해석 — 원하시면 직접 수정 가능 (별도 데이터 파일)
